ABOUT THE PROJECT

Turning EV Data into Meaningful Insights

The electric vehicle industry is evolving with developments in vehicle design, battery technology, and changing customer expectations. This project provides a visual way to explore selected aspects of that market using the data available in the project dataset.

The dashboard supports visual exploration, while the story helps communicate the analysis in a structured and accessible format. The goal is to make market information easier to interpret and support data-informed discussion.

Tableau Public Data Visualization Market Analysis Interactive Dashboard

Project Goal & Expected Outcomes

The project aims to present electric vehicle market data in a clear, visual, and accessible way. Through the dashboard and story, users can explore available indicators, compare categories, identify patterns, and develop a better understanding of the EV market. The project also demonstrates the use of Tableau to communicate data analysis through interactive visualizations.
